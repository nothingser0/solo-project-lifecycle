# Executive Stakeholder Deck Template

> **Purpose**: Present project status to C-level executives  
> **When**: Monthly executive reviews or major decision points  
> **Target**: Enterprise projects requiring executive buy-in

---

## Deck Guidelines

**Length**: 10-15 slides maximum

**Duration**: 20-30 minute presentation + 10 min Q&A

**Audience**: CEO, CTO, CFO, VP Engineering, Board members

**Tone**: Executive summary style (high-level, not technical details)

**Format**: PowerPoint, Google Slides, or Keynote

---

## Slide Structure

### Slide 1: Title & Summary

**Title**: [Project Name] - [Month] Executive Review

**Subtitle**: [Date]

**Presented by**: [Your Name, Title]

**One-line summary**: 
```
Project is [on track / at risk / off track] to deliver 
[key outcome] by [date]
```

**Example**:
```
Customer Portal Redesign - October 2024 Executive Review

Project is ON TRACK to launch Q4 2024, 
delivering 30% improvement in user engagement

Presented by: Sarah Chen, Project Manager
Date: October 4, 2024
```

## Presentation Tips

### Before Presentation

**24 Hours Before**:
- [ ] Send deck to attendees (let them pre-read)
- [ ] Prepare backup slides (detailed data if asked)
- [ ] Practice presentation (time yourself)
- [ ] Test Zoom/tech setup

---

### During Presentation

**Opening (2 min)**:
- Start with executive summary (green/yellow/red status)
- State one key message: "We're on track to launch Dec 1"

**Body (15 min)**:
- Walk through slides concisely
- Highlight wins and risks
- Focus on decisions needed

**Closing (3 min)**:
- Recap key message
- Restate ask (decisions/budget needed)
- Open for Q&A

---

### After Presentation

**Within 24 Hours**:
- [ ] Send slide deck + notes
- [ ] Document decisions made
- [ ] Follow up on action items

## Design Guidelines

**Visual Style**:
- Clean, professional
- Company branding (logo, colors)
- Minimal text (bullet points, not paragraphs)
- Visuals over text (charts, graphs, icons)

**Color Coding**:
- 🟢 Green: On track, positive
- 🟡 Yellow: At risk, caution
- 🔴 Red: Off track, urgent
- 🔵 Blue: In progress, neutral

**Fonts**:
- Sans-serif (Arial, Helvetica, Roboto)
- Slide titles: 32pt
- Body text: 18-24pt
- Don't go below 18pt (hard to read)

## Common Mistakes

**❌ Too Technical**:
```
"We refactored the ORM layer to use repository pattern with 
dependency injection for better testability..."
```
**✅ Executive-Friendly**:
```
"Improved code quality, making future changes faster and safer"
```

---

**❌ Too Much Detail**:
- 50-slide deck
- Tiny font
- Wall of text

**✅ Executive-Appropriate**:
- 10-15 slides
- Large font (18pt+)
- Bullet points

---

**❌ Hiding Bad News**:
```
"Everything is going great!" (when it's not)
```
**✅ Transparent**:
```
"We hit a 2-week delay, here's why and how we're fixing it"
```

## Notes

**Executives have short attention spans**: Get to the point fast

**Use visuals**: Charts > tables > text

**Be honest**: Hiding problems destroys trust

**End with ask**: What do you need from them?
