## Why Nuxt?

**Best for:**
- Vue developers wanting SSR/SSG
- SEO-critical applications
- Content-heavy sites (blogs, documentation)
- Teams with Vue expertise

**Stack:**
- Nuxt 3
- Vue 3 Composition API
- TypeScript
- Pinia for state management
- Nitro server engine
