## Why Astro?

**Best for:**
- Content sites (blogs, marketing, documentation)
- Static site generation
- Multi-framework support (React/Vue/Svelte in one project)
- Minimal JavaScript

**Stack:**
- Astro 4
- Framework agnostic (bring your own: React/Vue/Svelte)
- Markdown/MDX content
- TypeScript
- Deployed on Netlify/Vercel
