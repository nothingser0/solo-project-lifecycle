# Training Plan Template

> **Purpose**: Train client team on system usage and maintenance  
> **When**: M10 Deployment or M11 Handover  
> **Target**: Enterprise projects requiring client self-sufficiency

---

## Training Objectives

**Goals**:
- Client team can use system independently
- Client team can perform basic troubleshooting
- Client team can add content/users
- Reduce post-launch support requests

**Success Criteria**:
- 90% of users can complete core tasks without help
- Support ticket volume <10/week after 1 month
- Client satisfaction score >4/5

---

## Training Audience

### End Users
**Who**: Day-to-day system users (50-500 people)

**Training Needs**:
- How to log in
- Core workflows (create order, submit report, etc.)
- Navigation
- Common tasks

**Training Method**: Video tutorials + user guide

**Duration**: 30 minutes

---

### Power Users / Admins
**Who**: Team leads, admins (5-10 people)

**Training Needs**:
- All end user tasks
- User management (add/remove users)
- Content management
- Reports and analytics
- Basic troubleshooting

**Training Method**: Live session + admin guide

**Duration**: 2 hours

---

### Technical Team / IT
**Who**: Client's IT staff (1-3 people)

**Training Needs**:
- System architecture
- Deployment process
- Database backups
- Monitoring and alerts
- Troubleshooting
- Security procedures

**Training Method**: Live session + technical documentation

**Duration**: 4 hours

---

## Training Materials

### 1. User Guide (End Users)

**Format**: PDF, 20 pages

**Contents**:
1. **Introduction** (2 pages)
   - What is the system?
   - Who should use it?
   - How to get help

2. **Getting Started** (3 pages)
   - Logging in
   - Password reset
   - Navigation overview

3. **Core Tasks** (10 pages)
   - Task 1: Create new order (step-by-step screenshots)
   - Task 2: Submit report
   - Task 3: View analytics
   - Task 4: Export data

4. **Troubleshooting** (3 pages)
   - "I forgot my password"
   - "Page won't load"
   - "Error message appears"

5. **FAQ** (2 pages)
   - Common questions

**Example Page**:
```
Task: Create New Order

Step 1: Click "Orders" in the main menu
[Screenshot: Main menu with Orders highlighted]

Step 2: Click "New Order" button
[Screenshot: Orders page with New Order button]

Step 3: Fill in order details
- Customer name (required)
- Product (dropdown)
- Quantity (number)
- Delivery date (calendar picker)
[Screenshot: Order form]

Step 4: Click "Submit"
[Screenshot: Submit button]

Result: You'll see "Order created successfully"
[Screenshot: Success message]
```

## Training Environment

**Separate from Production**:
- URL: https://training.yourcompany.com
- Demo data (not real customer data)
- Reset nightly (users can experiment freely)

**Demo Data**:
- 50 sample orders
- 10 sample users
- 20 sample products

**Purpose**: Users can practice without fear of breaking production

---

## Training Assessment

**Quiz** (Optional):
- 10 multiple choice questions
- Pass: 8/10 correct
- Certificate of completion

**Example Questions**:
```
1. How do you create a new order?
   a) Click "New Order" button
   b) Email support
   c) Call customer service
   d) Refresh the page
   
2. What should you do if you forget your password?
   a) Create a new account
   b) Click "Forgot Password" on login page
   c) Call IT support
   d) Use a friend's account
```

## Training Checklist

**Preparation**:
- [ ] Identify training audience (end users, admins, IT)
- [ ] Create training materials (guides, videos, slides)
- [ ] Set up training environment (demo data)
- [ ] Schedule training sessions
- [ ] Send invitations

**Delivery**:
- [ ] Session 1: End user training (1 hour)
- [ ] Session 2: Hands-on practice (1 hour)
- [ ] Session 3: Admin training (2 hours)
- [ ] Session 4: Technical training (4 hours)
- [ ] Record all sessions (post videos)

**Follow-Up**:
- [ ] Send training materials (guides, videos)
- [ ] Offer office hours (first 2 weeks)
- [ ] Monitor support tickets (identify knowledge gaps)
- [ ] Send satisfaction survey
- [ ] Update materials based on feedback

---

## Notes

**Record everything**: Users will re-watch videos

**Demo, don't lecture**: Show, don't tell

**Hands-on practice**: Learning by doing is most effective

**Expect questions**: Plan extra time for Q&A
