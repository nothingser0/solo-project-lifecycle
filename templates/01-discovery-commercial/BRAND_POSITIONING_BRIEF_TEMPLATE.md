## 5. Proof Points (4–5)

| # | Proof | Type | Verifiable how |
| :-: | :--- | :--- | :--- |
| 1 | | Feature / fact / evidence | |
| 2 | | | |
| 3 | | | |
| 4 | | | |

Every proof must directly support the statement in §4. A proof that supports a different claim is a different position.

**Proof that is missing is not proof you may invent.** If a claim needs a number you do not have, write `[NEED: <what you need>]` in the Verifiable-how column and ask. An invented statistic is worse than a missing one, because it survives into the sales deck and the pitch.

---

## 5.1 The Story Test (before any of the above is written)

Positioning is not built from adjectives. It is built from one true story: the moment behind the product, what it cost, and what changed. Before filling §1–§5, answer these four. A story that fails all four is not ready — dig instead of writing around the gap.

| Test | Question | If it fails, ask |
| :--- | :--- | :--- |
| **Surprise** | Is there a number in the story that would surprise a colleague? | "What surprised you most?" |
| **Near-failure** | Is there a moment where it almost didn't work? | "What did it cost before it worked?" |
| **Wrong belief** | Did you believe something that turned out to be false? | "What did you delete, undo, or regret?" |
| **Retellability** | Would you tell this story at dinner without being asked? | "What do customers say about this, verbatim?" |

**Boring-but-true beats interesting-but-invented** — but the reason to keep digging is that there is almost always a true story that is also interesting. Writing from a weak story produces generic positioning no amount of craft can rescue.

**Category check** (pairs with §1): the category is the mental shelf the buyer files you on, because that shelf decides who you are compared against and which promises are table stakes. If you resist picking a shelf ("we're a new category"), ask what the buyer will *mistake* you for. That is the shelf.

## 6. Refusals (3–4) — what we will not be

- [Brand] is **not** for people who want [X].
- [Brand] will **never** compete on [Y].
- [Brand] does **not** try to be [Z].

> A position that excludes nobody attracts nobody. These are the sharpest lines in the brief.

## 7. Positioning Red-Flag Self-Check

- [ ] Could this statement apply to a named competitor? → **fails**
- [ ] Is the audience "everyone who wants quality"? → **fails**
- [ ] Is the differentiator a table stake ("great service", "easy to use")? → **fails**
- [ ] Are there no proof points? → **fails**
- [ ] Does the territory require a capability we do not have? → **aspirational, not actual**
