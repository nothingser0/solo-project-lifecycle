## 7. AI Logo Generation Prompts

**Use these prompts with ChatGPT (DALL-E), Midjourney, or Leonardo.ai:**

### Prompt 1: Modern Minimalist Icon + Text
```
Create a modern, minimalist logo for "[Project Name]", a [industry] platform.
Style: Clean geometric icon + sans-serif wordmark, flat design, [primary color hex] and [secondary color hex].
Icon concept: [e.g., "Abstract shield representing security" / "Upward arrow for growth"].
Mood: Professional, trustworthy, tech-forward.
Output: SVG-ready vector, transparent background, suitable for web/mobile.
```

### Prompt 2: Bold Wordmark (Text-Only)
```
Design a bold wordmark logo for "[Project Name]".
Font style: [Sans-serif / Serif], weight: 700 (bold), color: [hex].
Letter customization: [e.g., "First letter 'F' stylized with geometric cut"].
Mood: [e.g., "Strong, confident, modern"].
Output: Vector format, works at small sizes (favicon-ready).
```

### Prompt 3: Abstract Symbol
```
Create an abstract geometric logo symbol for "[Project Name]".
Concept: [e.g., "Interlocking circles representing collaboration" / "3D cube for structure"].
Color: [primary hex], style: flat 2D or subtle gradient.
Must work as: App icon (square), favicon (tiny), and next to text.
Output: SVG vector, minimal detail for scalability.
```

### Prompt 4: AI Logo Generator (LogoAI / Brandmark)
If using dedicated logo AI tools:
1. Input: Company name, industry, color preferences
2. Select style: Modern, Minimal, Professional
3. Generate 10+ variations
4. Download SVG + PNG variants
5. Refine in Figma if needed (adjust spacing, export variants)

## 8. Evaluation Checklist

Before finalizing logo, check:
- [ ] **Scalability**: Readable at 16x16px (favicon size)?
- [ ] **Simplicity**: No unnecessary details (simpler = more memorable)?
- [ ] **Uniqueness**: Doesn't look like competitor X?
- [ ] **Versatility**: Works on white, black, and colored backgrounds?
- [ ] **Timelessness**: Avoids trendy effects (gradients, shadows) that age poorly?
- [ ] **Relevance**: Communicates brand personality (professional/playful/modern)?
- [ ] **File formats**: SVG exported and tested in browser?

## 10. Implementation Notes

### CSS/HTML Usage
```html
<!-- Header logo (full version) -->
<img src="/logo/logo-full.svg" alt="[Project Name]" height="40" />

<!-- Favicon -->
<link rel="icon" type="image/x-icon" href="/favicon.ico" />
<link rel="icon" type="image/png" sizes="32x32" href="/logo/logo-icon-32.png" />

<!-- Apple touch icon (iOS) -->
<link rel="apple-touch-icon" href="/logo/logo-icon-180.png" />

<!-- Open Graph (social sharing) -->
<meta property="og:image" content="https://yourdomain.com/logo/logo-icon-1024.png" />
```

### Dark Mode Variant
```css
/* Auto-invert logo in dark mode */
@media (prefers-color-scheme: dark) {
  .logo {
    filter: invert(1); /* If logo is black on white */
  }
}
```
